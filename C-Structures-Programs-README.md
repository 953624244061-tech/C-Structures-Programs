# C Structures Programs

This repository contains three basic C programs demonstrating the use of **structures in C**.

## Programs Included

### 1. Student Structure
**File:** `student.c`

Creates a `Student` structure with:
- Name
- Roll Number
- Marks

The program reads the details of one student and displays them.

### 2. Employee Structure
**File:** `employee.c`

Creates an `Employee` structure with:
- ID
- Name
- Salary

The program reads the details of one employee and displays them.

### 3. Book Structure
**File:** `book.c`

Creates a `Book` structure with:
- Title
- Author
- Price

The program reads the details of one book and displays them.

## How to Run

Make sure GCC is installed.

Compile and run each program using:

```bash
gcc student.c -o student
./student
```

```bash
gcc employee.c -o employee
./employee
```

```bash
gcc book.c -o book
./book
```
